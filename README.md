# 兴风作浪 V2.0.0

Web-based action game built with Phaser 3 and ES modules.

## Run locally

Serve this directory with any static HTTP server and open `index.html`. Direct `file://` loading is not recommended because ES module and asset loading rules vary by browser.

## Project layout

- `src/scenes/` — title and gameplay scenes
- `src/player/` — player controller and presentation
- `src/enemies/` — enemy and boss actors
- `src/systems/` — spawning, status, VFX, music, and text systems
- `src/config/` — gameplay and visual configuration
- `assets/` — game art and audio
